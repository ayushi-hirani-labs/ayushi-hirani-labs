## How an engagement takes shape

1. **Understand the workflow** — map the current process, systems, bottlenecks, and desired outcome.
2. **Define a useful first milestone** — agree on scope, acceptance criteria, and responsibilities.
3. **Build and evaluate** — demonstrate progress with realistic examples and visible failure handling.
4. **Hand over and improve** — provide documentation, operational guidance, and a plan for maintenance.

Technical contributors and implementation responsibilities are agreed before work begins.
